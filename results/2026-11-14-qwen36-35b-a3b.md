# Qwen3.6-35B-A3B on one BC-250 — 2026-11-14

Board: AMD BC-250, **40 CU unlocked** (stock boards have 24 CU and are slower), GPU capped at 1500 MHz (cyan-skillfish-governor-smu,
900 mV), max 75 °C during the runs. Fedora 43, Mesa 25.3.6 (RADV GFX1013), headless.
Model: `Qwen3.6-35B-A3B-UD-IQ2_M.gguf` (Unsloth, 10.72 GiB), KV cache q8_0, flash attention on.
Software: llama.cpp b12370 + the patches in this repo (earlier rebase, same code paths).

## llama-bench — generation (tg128, 3 reps, 45 s cool-down between points)

| Setting | tok/s |
|---|---|
| upstream default (`kq=2`, `iq=4`) | 85.11 ± 2.47 |
| **patched (`kq=4`, `iq=4`)** | **86.09 ± 0.36** |
| `kq=4`, `iq=8` | 85.30 ± 1.37 |
| `kq=4`, `iq=2` | 83.81 ± 1.64 |
| patched, 4096 tokens in context | 81.58 ± 0.19 |
| patched, 16384 tokens in context | 76.58 ± 0.27 |

The `kq` difference is within noise on this model: IQ2_M is mostly i-quant weights, and
`kq` only affects K-quant tensors. `scripts/kq-ab.sh` is the proper test on Q4_K_M models.
